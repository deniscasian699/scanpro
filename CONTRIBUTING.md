# 🤝 Contributing to ScanPro

Thank you for your interest in ScanPro! 📱

</div>

---

ScanPro is a **proprietary application.** This repository is used for
public documentation, legal documents, issue tracking, and transparency.

Direct code contributions are not accepted at this time.

---

## 💬 How You Can Help

### 🐛 Report a Bug

Found a bug? Please open a
[GitHub Issue](https://github.com/deniscasian699/scanpro/issues/new?template=bug_report.md) with:

- Device model and Android version
- ScanPro version *(found in Settings → About)*
- Steps to reproduce the bug
- Expected vs. actual behavior
- Screenshots or recordings *(if helpful)*

Or report directly at **[bugs.rdcapps.com](https://bugs.rdcapps.com)**

### 💡 Suggest a Feature

Have an idea? Open a
[Feature Request](https://github.com/deniscasian699/scanpro/issues/new?template=feature_request.md) with:

- The problem you're trying to solve
- Your proposed solution
- Why it would benefit ScanPro users

### 🌐 Translation

If you notice an incorrect label or a translation error in the documentation,
please let us know at
**[support@rdcapps.com](mailto:support@rdcapps.com)**

### ⭐ Rate & Review

Leaving a positive rating and review on
[Google Play](https://play.google.com/store/apps/details?id=com.qrscanpro.dc) helps other users
discover ScanPro. It's the best free way to support the app.

### ❤️ Support Development

Consider a [Supporter plan](https://play.google.com/store/apps/details?id=com.qrscanpro.dc) to
help keep ScanPro available and actively maintained. Supporter removes ads;
Premium unlocks features and includes ads.

---

## 📋 Issue Guidelines

- Search existing issues before opening a new one to avoid duplicates.
- Use clear, descriptive titles.
- Include as much context as possible.
- Be respectful and constructive.

---

## 🤝 Code of Conduct

All interactions in this repository are expected to meet basic standards
of respect and professionalism.

Harassment, spam, or abusive behavior will result in removal.
